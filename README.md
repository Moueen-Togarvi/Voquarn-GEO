# Voquarn GEO

Minimal Next.js project setup. Product frontend and backend implementation have
been removed.

## Stack

Next.js 16 · React 19 · TypeScript · Tailwind CSS v4

## Getting started

### 1. Install dependencies

```bash
npm install
```

### 2. Run

```bash
npm run dev
```

Add an App Router entry point under `src/app`, then open http://localhost:3000.

## Scripts

| Script                | What it does                              |
| --------------------- | ----------------------------------------- |
| `npm run dev`         | Start the dev server                      |
| `npm run build`       | Create a production build                 |
| `npm run format`      | Format with Prettier                      |
| `npm run lint`        | Run ESLint                                |
